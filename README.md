# Projeto 01 — Análise de Vendas com Power BI
![Dashboard de Análise de Vendas](imagens/dashboard final.png)

## Sobre o projeto

Projeto desenvolvido com o objetivo de analisar o desempenho de vendas utilizando a base de dados AdventureWorks2022, disponibilizada para fins de treinamento.

A análise contempla faturamento, quantidade vendida, categorias de produtos, desempenho por território e produtos de maior destaque.

## Ferramentas utilizadas

- SQL Server
- Power BI Desktop
- Power Query
- DAX

## Etapas do desenvolvimento

1. Importação e tratamento dos dados.
2. Modelagem e relacionamentos entre tabelas.
3. Criação de medidas e indicadores com DAX.
4. Desenvolvimento de gráficos e dashboard.
5. Interpretação dos resultados e identificação de oportunidades de investigação.

## Principais indicadores

- Faturamento total: aproximadamente R$ 109,8 milhões.
- Quantidade total vendida: aproximadamente 275 mil unidades.
- Total de pedidos: aproximadamente 31 mil.
- Ticket médio: aproximadamente R$ 399,57.

## Principais Insights

- A categoria Bikes representa aproximadamente 87% do faturamento.
- Outras categorias apresentam volume expressivo de vendas, mas participação menor na receita.
- Os produtos de maior faturamento não são necessariamente os mais vendidos em quantidade.
- Existem diferenças de faturamento entre os territórios, que podem ser investigadas considerando clientes ativos e quantidade de pedidos.
